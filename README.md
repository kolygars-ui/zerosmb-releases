# ZeroSMB

Кроссплатформенный клиент NAS на **Rust + Tauri**.
Работает с SMB2/3, встроенными ZeroTier и WireGuard, галереей телефона,
синхронизацией папок и локальным API для ИИ-агентов.

Поддерживаются **Windows**, **Linux** и **Android**.

Готовые сборки публикуются в разделе **Releases** этого репозитория.

## Возможности

### Подключение к NAS

В настройках и мастере первого запуска выбирается один из трёх режимов:

- **Local** — прямое SMB-подключение по LAN-IP или имени NAS.
- **ZeroTier** — встроенный клиент ZeroTier (libzt), без отдельного приложения.
  В мастере первого запуска можно сразу выбрать свой файл `planet` (корневой
  сервер ZeroTier).
- **WireGuard** — встроенный userspace-клиент WireGuard на `onetun`, без TUN,
  прав администратора и отдельного VPN-приложения.

Для ZeroTier и WireGuard SMB-трафик заворачивается в локальный TCP-прокси:
приложение подключается к `127.0.0.1`, а прокси передаёт поток через VPN.
Обычные настройки SMB (хост, share, порт, логин, пароль, базовая папка)
находятся отдельно от выбора режима.

### Файлы

- Просмотр папок и файлов, дерево слева, табличный или списочный вид.
- Скачивание, загрузка, создание папок и удаление файлов/папок.
- Подтверждение удаления в собственной модалке.
- Настройка размера шрифта, вида списка и цветов папок/файлов.
- Офисные документы (DOCX, XLSX, PPTX, ODT, ODS, ODP, EPUB и другие) по умолчанию
  открываются в системном приложении с оригинальным форматированием и листами.
  В настройках можно выключить это и использовать встроенный текстовый просмотр.
- Браузер архивов ZIP и RAR: список файлов, встроенный предпросмотр
  изображений/видео/текста/PDF, открытие документов в системном приложении
  и скачивание отдельного файла из архива.
- Для остальных форматов — открытие во внешнем системном приложении без
  ручного скачивания.
- Панель передач на ПК: текущий файл, процент, общий прогресс всех
  одновременных передач, история активных и завершённых файлов.

### Галерея

- Фотографии и видео телефона через MediaStore.
- Загрузка в выбранную папку галереи на NAS.
- Автоматическое создание папки галереи, если её нет.
- Скачивание и синхронизация выбранных альбомов/файлов.
- Настройка количества карточек в строке: от 2 до 12.
- Показ/скрытие вкладки «Галерея».

### Синхронизация

- Пять режимов: ручная/автоматическая загрузка, ручное/автоматическое
  скачивание и зеркалирование.
- Планировщик по интервалу.
- Отдельное разрешение на удаление файлов в задании.
- Редактирование существующих заданий.

### Оформление

- Плитка **«Персонализация»**: шрифт файлов и дерева, вид списка,
  карточки галереи, видимость галереи.
- Выбор цвета фона через RGB-ползунки с HEX-превью.
- Кнопка возврата к исходному цвету.
- Для светлых цветов автоматически включается светлая схема с тёмным текстом.

### Системная интеграция

- **Windows**: установка/перенос, автозапуск, меню «Пуск», ярлык на рабочем
  столе, трей, уведомления, single-instance, автообновление через setup.
  через пакетный менеджер.
- **Android**: foreground-сервис с прогрессом, уведомления, сохранение в
  Downloads/Gallery, запрос разрешений.

### API для ИИ-агентов

Отключаемый по умолчанию локальный HTTP API на `127.0.0.1:17845`.
Токен не требуется. Доступны отдельные разрешения и список запрещённых папок,
которые выбираются через встроенный браузер папок NAS.

Маршруты:

- `GET /` и `GET /v1/help` — полные инструкции для агента.
- `GET /v1/info` — права, share, basePath, запрещённые папки.
- `GET /v1/files?path=` — список файлов.
- `GET /v1/file?path=` — скачать файл.
- `PUT /v1/file?path=` — загрузить новый или изменить существующий файл.
- `POST /v1/folder?path=` — создать папку.
- `DELETE /v1/path?path=` — удалить файл или папку рекурсивно.

Права: скачивание/чтение, изменение, загрузка, создание папок, удаление.
Запрет папки действует на неё и всё содержимое; удаление родительской папки
с запрещённой вложенной папкой блокируется.

## Ограничения

- Android APK собран в debug-варианте и не подписан для Google Play.
- Пароль к зашифрованным ZIP/RAR-архивам пока не запрашивается.
- Предпросмотр архивов загружает архив в память; файлы больше 512 МБ
  открывать через встроенный браузер нельзя.
- Воспроизведение видео зависит от кодеков WebView. H.264/AAC/WebM обычно
  работают; HEVC и некоторые контейнеры могут не поддерживаться.
- Пароль SMB хранится в Windows Credential Manager / Secret Service,
  на Android — в приватном каталоге приложения.
- API ИИ доступен без токена только на `127.0.0.1`; любой локальный процесс
  может обратиться к нему, если доступ включён. Права и запреты папок при этом
  продолжают действовать.
